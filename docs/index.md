## 课程路线

课程沿着“公司与财报 → 估值与市场 → 因子逻辑 → 因子检验 → 组合构建 → 回测可信度 → 风险与实盘”逐步展开。每一章只引入当前需要的知识，最终形成一套可解释、可回测、可交易的 A 股只做多选股系统。
